01 / Overview

A flexible layer for your
coding-agent setup.

Free Claude Code is a community project that provides an Anthropic-compatible proxy and integrations for supported model providers. It is designed to let you configure model routing without changing the coding-agent workflow more than necessary.

⌘

One workflow, provider options

Configure supported providers and model choices for your setup. Availability and capabilities depend on the provider and selected model.

⌂

Hosted or local

Use supported hosted services or compatible local runtimes such as LM Studio or llama.cpp, where configured.

↗

Built in the open

Review the source, report issues, and contribute improvements through the public GitHub repository.

02 / Features

Tools for a more configurable workflow.

Feature descriptions below are based on the public repository README. Check the repository for the current implementation and requirements.

01

Provider integrations

Route requests through supported providers, including NVIDIA NIM, OpenRouter, DeepSeek, LM Studio, and llama.cpp. Check the README for the current list.

02

Per-model routing

Configure provider/model choices for model names such as Opus, Sonnet, Haiku, and a fallback, subject to compatibility.

03

Streaming and tool handling

The project describes support for streaming and handling tool-use or reasoning formats across compatible provider responses.

04

Messaging integrations

Optional Discord or Telegram workflows are described in the repository. Review setup, permissions, and security guidance before enabling them.

05

Local model options

Configure compatible local runtimes for workflows where you prefer to run a model on your own machine.

06

Open development

Browse the code, open an issue, or submit a pull request through GitHub. Contributions should follow the repository's current guidelines.

uv tool install --force git+https://github.com/Alishahryar1/free-claude-code.git

Start the server

Start the local service after completing the repository's prerequisites and configuration.

Configure a provider

Follow the provider-specific instructions in the README. Keep API keys private and never commit them to Git.

Provider setup guide ↗

Note: The software may be free to install, but third-party providers can charge for usage or enforce their own quotas. Do not assume that all models or API calls are free.
